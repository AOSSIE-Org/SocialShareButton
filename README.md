<h1>SocialShareButton</h1>
</div>

A lightweight and customizable **social sharing component** for modern web applications.  
Built with **pure JavaScript**, zero dependencies, and works across all frameworks.

---

## 🚀 Features

- 🌐 Supports multiple platforms: WhatsApp, Facebook, X, LinkedIn, Telegram, Reddit, Email, Pinterest  
- 🎯 Zero dependencies (pure vanilla JS)  
- ⚛️ Compatible with React, Next.js, Vue, Angular, and more  
- 🔄 Automatically detects page URL and title  
- 📱 Fully responsive and mobile-friendly  
- 🎨 Custom themes (dark/light)  
- ⚡ Lightweight (<10KB gzipped)  

---

## 💻 Tech Stack

- **Frontend:** JavaScript (Vanilla JS)
- **Styling:** CSS
- **Distribution:** CDN / npm
- **Compatibility:** All major frameworks

---
